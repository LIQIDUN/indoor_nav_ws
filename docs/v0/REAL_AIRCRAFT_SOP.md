# 真机 SOP（仅文件交付，本轮未执行）

## 放行门槛

F0/F1/F2/F3 对应项目全部通过、人工签署版本/硬件/场地检查后才建议进入飞行阶段。当前 **F2 BLOCKED**，只允许 R0 非飞行接口调查，不进入自动航点实飞。软件门槛不等于桨叶防护/物理隔离。任何自动SITL脚本不得在机载运行。

## R0 拆桨、只读接口

1. 拆除全部桨叶，固定机体，确认电源/急停/RC，记录硬件和FC固件Git/参数快照。
2. 启动机载**最新版**采集入口；检查只有一个Master/MAVROS/FCU串口占用者，保持音频协议不动。确认实机 `/use_sim_time` 非true，不继承SITL环境。
3. 记录Fake GPS实现/协议/物理端口、UWB有效测量序号/质量与FC EKF融合证据；完成缺口文档要求。禁止创建第二注入源。
4. V0默认只读启动；检查pose/速度frame、stamp、GPS/EKF有效性；手持前/右/上验证符号与yaw；重启/跳点/断流/冻结测试，必须锁存而不是重捕获原点。
5. 验证RC从GUIDED切至预定备用模式，GPS失效后的高度/姿态行为、GCS/RC丢失failsafe；室内不默认RTL。没有桨也不自动ARM。
6. 只读核验速度/加速度参数及单位，与实际目标固件对照。生产V0不会替人配置；任何参数修改应另行批准、备份、复核。

## R1 人工低空悬停 + dry_run

仅在F2等放行后。隔离场地、护具/围挡、合格飞手与观察员；先人工验证原位置/高度保持、Fake GPS质量、RC接管。V0 `enable_control:=false dry_run:=true`，核对冻结原点/yaw、目标在真实安全包络内，不发送运动目标。测pose age/循环抖动及CPU满载分布，人工确定门槛，不因误报随意扩大围栏。

## R2 单点

飞手人工ARM/起飞/悬停并切GUIDED，确认备用模式可随时切。审阅仅一个0.2–0.3m点、z=0、速度已手工限至审计值；显式开启两把控制开关，明确调用start。观察真实运动/速度/模式；异常立即RC接管，abort仅为软件停发，不当作刹车。导航不自动LAND/DISARM。

## R3 小方形/往返

R2多次重复通过后，逐步增加前/右/回原点，保留同一P0/yaw0。逐点连续稳定与停留时间、实际路径/速度、软围栏与墙壁安全余量都由飞手/观察员核对。结束保持最后目标，飞手切出GUIDED并人工降落。重新任务先DISARM与显式reset/start，不自动续飞。

## R4 满负载联合

保持XVF16kHz与IM72 48kHz、位宽/增益/分块/话题原样；ESC/振动/音频与ARM/DISARM录包同时运行。确认新增V0话题只追加到现有列表。测试导航停止不杀录包、单音频故障不抢模式；资源劣化触发导航自身健康撤销。MAVROS断连依靠预验证FCU/RC应急，不依赖还能通信的watchdog。

## 每次人工签核与归档

记录FC firmware/EKF源/Fake GPS协议和版本、RC开关/备用动作、限速单位和实际速度、碰撞边界与人员分工、YAML hash/Git/dirty、bag/FC日志、pose age和setpoint间隔、开始/到达/异常事件。DISARM自动停包为原采集逻辑，不代表导航杀录制。任何失败立即停止升级；不以SITL PASS替代现场风险评估。
