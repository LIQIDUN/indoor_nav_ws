# 安全边界与尚不能证明的结论

- 2026-11-03 科研策略差异见 `V0_RESEARCH_UPGRADE.md`，本次本地验证见 `V0_RESEARCH_VALIDATION_20261103.md`。严格 YAML 字节保持不变。research 不强制悬停历史、不因持续超速本身中止、航点超时等待、WPNAV 性能参数仅诊断；这些不是放弃飞手悬停确认或证明高速运动安全。GUID_OPTIONS/EKF来源/固件与通信、定位、围栏、倾角、租约保护仍强制。
- 持续位姿/速度冻结不一致仍是硬联锁：现有1.5秒窗口需要全窗口速度超阈值且位置几乎不动，单次速度尖峰不满足。没有独立证据可将持续矛盾视为无害，故本次不放宽跳点/冻结阈值、不绕过GPS/EKF健康。Manager与Watchdog共同使用同一个Health实现和同一份YAML哈希。
- 新 USB 入口默认只读并默认严格 level 配置；已有 MAVROS 必须 start_mavros:=false。stream 请求只复用 MAVROS 服务，不新开串口、不产生控制输出。服务无 success/频率确认语义；五组请求、重连与软件回归不能代替真实链路长期话题频率验收。
- 本交付是软件与仿真证据，不是物理安全认证。F2专项模拟/协议调查已取消；用户确认UWB经飞控GPS接口参与EKF。本轮仅恢复本地开发和隔离SITL，未获真机操作授权；最新实测及原始FAIL见 `FAST250_DYNAMIC_SITL_REPORT_20261028.md`。R0及真实硬件/RC/场地检查不可由SITL替代。
- 生产代码不ARM/起飞/降落、不写FC参数、不切回GUIDED；gate是唯一FC位置目标及可选BRAKE模式请求出口，manager只给意图。人工切出GUIDED后锁存，明确DISARM/reset/start才可再次授权。
- 默认exit_action=manual_takeover仅停发，不能称为刹停。显式brake_if_position_healthy仅在既有任务租约、独立定位/GPS/EKF健康、ARM/GUIDED及审计固件/参数新鲜时单次请求BRAKE；模式返回仍须实测mode/速度确认。定位失效、断链、配置/时钟异常不盲目切模式；室内不默认RTL。
- gate沿用原watchdog进程并独占FC输出，独立接收定位；manager被kill/卡死不会由另一个发布者抢控制。gate自己死亡、Master/MAVROS死亡或CPU全阻塞时，不能保证FC动作，依赖预验证RC/FCU failsafe；没有硬实时或物理急停。示例SITL FS_GCS_ENABLE=0不构成真机失联保护模板。
- gate的独立检查仍来自同一FC EKF，并非第二套独立定位源，不能证明公因定位错误不存在。控制gate须先见到IDLE且DISARM；不支持半空重启后自动接管，须落地重新授权。
- 单发布者检查为周期ROS图观测，存在检测窗口，不是原子安全锁或防恶意隔离；不要同时启动旧 supervisor 或其它控制插件输入。
- 软件边界相对 P0，不是房间地图，不含旋翼/机身碰撞模型；初始化高度不是 AGL。真实起点安全余量必须人工测量。
- pose跳点/时间异常会中止，绝不重捕获原点续飞；小幅、缓慢或同源一致性重定位仍可能漏检。真实定位质量/方向/EKF及断流/重定位行为留给R0核查，不再要求专项adapter或底层协议调查；下游EKF不能证明所有上游故障均可检出。上游Bool已改为显式可选增强项，默认普通GPS无此依赖。
- 零位移不是冻结。持续位姿/速度不一致检测仅覆盖部分故障；EKF位置与速度一起冻结或错误但自洽可漏检；上游Bool不等于完整测量质量认证。
- 消息新鲜度以ROS回调接收时间为主，并保留monotonic接收间隔上界；任务/周期期限仍用monotonic。原始header偏移、重复、单次回退只作诊断，不改写消息头、不再等同定位断流。ROS未初始化拒绝启动；归零/倒退清空旧接收状态、活动任务锁存；人工DISARM/reset后才能重新授权。收到缓存或重复值不证明物理定位正确，EKF/GPS/跳点/原点/冻结一致性保护仍保留，不能检测所有自洽的假定位。
- 目前只审计Copter4.5.7/MAVROS1.20.1；新参数WP_SPD、其它固件、其它frame插件不自动兼容。FC参数只读周期检查，不阻止地面站/飞手中途更改；短检测窗口仍存在。
- F3 mock只等价于消息大小和通信负载，不能证明ADC采样连续性、USB稳定性、24bit格式、增益或真实ESC；本地自动recorder源码的ARM/DISARM模拟测试应与真实硬件联合验收分开。真实机载R4必需。
- FC模式检查与SetMode请求之间不是飞控侧原子操作，人工切模式/通信调度仍有竞态窗口；gate不重试或抢回GUIDED，真机默认manual_takeover，备用策略须现场另行批准。
- 进程/模式/速度/真值测试逐项查看 SITL_REPORT，不把未测行为标为通过。所有失败尝试保留；历史run_06不计入本轮成功次数。
